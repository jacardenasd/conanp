=======================================
VALIDACIONES AUTOMÁTICAS
=======================================

REQUERIDOS (4 campos):
  ✓ username (único, 3-50 caracteres)
  ✓ nombre (no vacío)
  ✓ apellido_paterno (no vacío)
  ✓ correo (válido, único)

VALIDACIONES ESPECIALES:
  ✓ RFC: 6 letras + 8 dígitos + 3 caracteres
  ✓ CURP: 18 caracteres específicos
  ✓ Email: Formato RFC 5322 + unicidad
  ✓ Username: Alfanumérico + guiones/puntos
  ✓ Fechas: Detección de formato + conversión automática
  ✓ Dependencias: jefe_id, unidad_id, adscripcion_id existen
  ✓ Enumerados: role, sexo, tipo_usuario validados
  ✓ Transacciones: Rollback en error (ACID)

=======================================
COMO USAR
=======================================

IMPORTAR USUARIOS:
  1. Admin → Usuarios → Importar
  2. Leer instrucciones en acordeones
  3. Descargar plantilla o llenar Excel
  4. Seleccionar archivo
  5. Clic "Cargar usuarios"
  6. Revisar resumen

VER HISTORIAL:
  1. Clic botón "Ver historial de importaciones"
  2. Filtrar si es necesario (fecha, admin, estado)
  3. Clic en ojo ( ) para ver detalles
  4. Clic en papelera (🗑) para eliminar lote

CAMPOS REQUERIDOS EN EXCEL:
  username, nombre, apellido_paterno, correo
  (y 15+ opcionales más)

=======================================
TESTING RECOMENDADO
=======================================

1. CASO: Usuario válido completo
   - Cargar archivo con 1 usuario válido
   - Verificar que se crea con ID único
   - Verificar que aparece en historial

2. CASO: Errores de validación
   - Omitir campo requerido (username)
   - Verificar que rechaza lote completo
   - Revisar mensaje de error específico

3. CASO: RFC duplicado
   - Importar usuario A con RFC = "ABC123XY456"
   - Intentar importar usuario B con mismo RFC
   - Verificar error de duplicado

4. CASO: Eliminación de lote
   - Importar 5 usuarios nuevos
   - Ir a historial
   - Clic eliminar lote
   - Verificar que BD no tiene esos usuarios

5. CASO: Actualización de usuario
   - Usuario ABC-123 existe con nombre "Juan"
   - Importar archivo con ABC-123 y nombre "Juan Carlos"
   - Verificar que se actualiza nombre
   - Verificar que aparece como "actualizado" en historial
